# PC Gaming Fixes

PC game troubleshooting: config editing, mods, input fixes, widescreen, keybindings.

## General Approach

1. Check **PCGamingWiki** first — most known issues, patches, and mods.
2. Look for community fix packs — ThirteenAG's Widescreen Fixes Pack, SilentPatch, DSOAL, etc.
3. When in-game menus freeze: bypass them, edit config files directly.
4. NFS Black Box games (MW 2005, Carbon, ProStreet, Undercover): see `references/nfs-blackbox-xtendedinput.md`.

## Reference Files

- `references/nfs-blackbox-xtendedinput.md` — NFS XtendedInput plugin: key format, paths, action list, menu-freeze workaround.
