# Books → Rules Skills

Конвейер превращения книги (PDF/ярлык на PDF) в book-rules скилл по образцу `book-rules-clean-code`: извлечение текста → карта структуры → дистилляция правил → сборка SKILL.md. Рабочая папка проекта пользователя: `C:/Users/Administrator/Documents/!LAMA/books to skills/` (там лежат .lnk-ярлыки на PDF, сами PDF на E:).

## Когда использовать

- Пользователь даёт книгу/PDF/ярлык и просит сделать скилл «по типу book-rules»
- Продолжение проекта «books to skills» (книги по психологии/психиатрии)

## Шаг 0 — Спросить направленность ДО дистилляции

Один вопрос решает форму всех правил: кто потребитель скилла?
- «для медсестры/специалиста» → правила ухода/работы
- «для меня, самопомощь» → инструкции переворачиваются в самонаблюдение: не «как ухаживать за пациентом», а «как распознать у себя, что делать со своей тревогой/реакцией»
Также спросить объём: пилот на 2-3 главах или вся книга сразу. Пользователь этого проекта выбирает: самопомощь + вся книга сразу.

## Шаг 1 — Найти реальный файл

Ярлык .lnk → цель: `python scripts/resolve_lnk.py "<path.lnk>"`. Цель может быть на другом диске (напр. E:). Проверить `ls -la` по найденному пути.

## Шаг 2 — Извлечь текст

`python scripts/extract_book_text.py "<book.pdf>" "<out>_text.txt"` — pymupdf, страницы разделены маркерами `===== PAGE N =====`, в конце печатает номера строк заголовков тем (границы лекций). Книги без текстового слоя: рендер страниц в PNG → PaddleOCR `lang='ru'` (RapidOCR кириллицу не тянет).

## Шаг 3 — Карта структуры

- `get_toc()` у учебников часто пуст — оглавление лежит текстом в конце книги: grep `ТЕМА|ЛЕКЦИ` по извлечённому файлу
- Записать границы: каждая тема = диапазон строк (напр. Тема 6: 1591-2060). Диапазоны нужны для делегирования

## Шаг 4 — Дистилляция делегированием (300К+ символов не влезают в контекст)

- Разбить книгу на 3-4 блока по ~3-6 лекций/глав, запустить параллельных субагентов через `delegate_task`
- Каждому: путь к текстовому файлу, точный диапазон строк, output_schema `{markdown: string}`, явный запрет выдумывать содержимое (работать только с текстом файла), язык вывода русский
- Единый формат секции для каждого блока:
  1. «Знания-маркеры» — признаки/механизмы/классификации кратко
  2. «Правила для себя» — MUST / SHOULD / MUST NOT (проверяемые действия, не пересказ)
  3. «Самодиагностика» — вопросы/чек-листы самооценки
- Диапазоны строк привязаны к маркерам `===== PAGE N =====`, читаются `read_file` c offset — если результаты субагентов потеряны, повторный запуск по тем же диапазонам идемпотентен

## Шаг 5 — Сборка и регистрация

- Frontmatter: `description` ≤ 60 символов (skill_manage create жёстко отклоняет длиннее с сообщением о бюджете — сокращать, а не спорить); `author`, `source` — откуда книга
- `skill_manage(action='create')` — личный скилл в `~/AppData/Local/hermes/skills/`; тяжёлые справочные куски — в `references/`
- Проверка: `skill_view(name)` → `readiness_status: available`

## Pitfalls

- Windows-пути с кириллицей в .ps1: PowerShell 5.1 читает скрипт в ANSI без BOM → Test-Path возвращает False на существующий файл. Не тратить время на .ps1 — парсить .lnk питоном (см. скрипт)
- Запуск PowerShell из bash: `$` съедается — `$sh` превращается в пустоту; писать команды файлом или экранировать
- Номера страниц в PDF ≠ номера строк текстового файла — делегировать по строкам, найденным в Шаге 3, а не «по страницам»
- Не добавлять главы «профессиональных качеств медсестры» в скилл самопомощи дословно — переформулировать в личные качества

## Verification

- Скилл зарегистрирован и `skill_view` показывает все секции
- Каждая тема книги представлена в body (ничего не потеряно при делегировании)
- Правила написаны в MUST/SHOULD/MUST NOT форме, без пересказа
