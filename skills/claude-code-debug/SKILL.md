# Claude Code Debug Assistant

Systematic debugging for Claude Code with reproducible test cases and comprehensive reporting.

## Debug workflow
1. Identify bug location and conditions
2. Create minimal reproduction case
3. Analyze root cause
4. Implement fix
5. Add test coverage
6. Verify behavior preservation

## Debugging rules
- Reproducible test cases only
- Clear error message formatting
- Comprehensive logging
- Graceful error handling
- Edge case coverage
- Performance considerations
