# Работа и право в Чехии — мигрант (Пльзень)

Пользователь: Karpov Alexandr, Пльзень, zaměstnanecká karta. Работник Ball Beverage Packaging (декоратор, машины Stolle/Concord, с 07.04.2026; ранее Safran Cabin до 09.2025, JTekt 05.2022–09.2024, до эмиграции — техник АТМ/терминалов, Днепр). Советы по работе/зарплате/переводам/CV обычно запрашиваются внутри «психо-комнаты» — состояние и файлы см. в pamyat-dnevnik.

## Рабочие правила
1. Актуальное право проверять по официальным источникам (ipc.gov.cz, mpsv.cz, mvcr.cz), не по памяти: нормы меняются. Давать ссылку на источник.
2. От его имени в документах никогда не писать самопризнаний («nezvládám», «не вытягиваю») — та же правда формулируется через режим/качество: «в текущем режиме качество нестабильно, предлагаю решение». Письменное признание ложится в папку §52f.
3. Бумажный след — защита: запросы письменно (HR), копии себе, сменный журнал, лог инцидентов с датами. Жалобы без фактуры в письма не включать.
4. «okamžitý nástup» в резюме для держателя карты без свободного доступа — юридически неправда (см. references/employee-card-rules.md).
5. Суммы/сроки перепроверять по его же файлам (plan_dolg_zarpata.txt) перед тем, как называть в ответе.
