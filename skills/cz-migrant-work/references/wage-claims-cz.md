# Взыскание зарплаты в Чехии

## Минимальная зарплата (официально, mpsv.cz, sdělení č. 356/2025 Sb.)
- 2026: 22 400 Kč/мес, 134,40 Kč/ч. 2025: 20 800 Kč/мес.
- Платить ниже минималки нельзя; доплата до минимума положена по §111 zákoníku práce, даже если в договоре указано меньше. Договорная ставка выше минимума = требовать ставку по договору.

## Пачки (výplatní pásky)
Выдаются ежемесячно по закону. Отсутствие = нарушение + бремя доказывания выплат лежит на работодателе: его пустота против слов работника и выписок.

## Лестница взыскания
1. Письменная výzva k zaplacení: сумма, месяцы, срок 10 дней, заказным + скан в мессенджер. Создаёт след и часто работает.
2. Жалоба в inspektorát práce (можно анонимно): невыплата + отсутствие пасок + зарплата ниже минималки = готовые составы, штрафы; акт инспекции = доказательство для суда.
3. Žaloba в okresní soud (по месту фирмы): пошлина ~4% (мин. 1000 Kč), можно просить освобождение при низком доходе; давность по зарплате — 3 года; при неявке ответчика — заочное решение.
4. При неплатёжеспособности работодателя: náhrada mzdy по з-ну 118/2000 Sb. через úřad práce (условия проверять актуальные — включая случай «не платит 3+ месяца»).

## Правила тактики
- Приговор суда ≠ деньги: сначала оценить имущество должника, потом выбирать суд или госсхему.
- Требовать только фактически отработанные месяцы; раздутый иск (за месяцы, когда не работал) разваливает весь кейс.
- Рычаг при живом HPP: работодатель платит pojistné ~33,8 % от базы — удержание дорогое для него. Размен: «подпишу dohodu (закрытие сегодня) в обмен на письменный график погашения долга», иначе výpověď (ещё 2 мес. платежей) + inspektorát + суд.
- Расторжение не требует согласия работодателя: výpověď работника без указания причины (§50/3), срок 2 мес. с 1-го числа следующего месяца; вручение — лично при свидетеле или заказным на sídlo фирмы.
