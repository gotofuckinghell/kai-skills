# Резюме под чешский рынок — убийцы отклика и правила

Найдено разбором реальных CV пользователя (папка Documents; боевой файл был CV.pdf — самый повреждённый).

## Убийцы отклика (проверять каждое CV перед отправкой)
1. Фраза про ожидание/бумаги: «Na OAMP se přihlásím... čekání 7–30 dní» → мгновенный отказ на массовых позициях. Заменить честной формулой статуса (см. employee-card-rules) или убрать до собеседования.
2. Машинный перевод без вычитки: «Robot pro elektroinstalace», «Nováčci s operačními systémy», украинские слова в чешском тексте («Nalashtuvannya»). Читается как неуважение.
3. Битый телефон: неверный код страны (+427), звёздочки/пропущенные цифры в текстовом слое PDF. Проверять сам файл, не исходник.
4. Рассинхрон между версиями: имя (Alexandr/Alex/Oleksandr), возраст, e-mail (два разных), название колледжа (ШАГ vs KROK — одна школа), уровень чешского. Одна каноническая версия данных.
5. Устаревший текущий работодатель и открытые даты («dosud» там, где уже ушёл) — проверяемая ложь.
6. Пустая вторая страница, protonmail с ником-«литом» (ism1337) — мелкие, но считываются.

## Правила
- Два жёстких шаблона (техник / оператор), без гибридов: адаптация = выбор шаблона, не смешивание. Рекрутер читает 7 секунд.
- Текущее место пользователя: Ball Beverage Packaging (декоратор, Stolle/Concord: смена клише и красок, настройка, контроль качества печати) с 04.2026 — сильная строчка и для техника, и для оператора. Safran Cabin — прошлое (до 09.2025).
- Технический шаблон: не обещать okamžitý nástup (карта!); честно про квалификацию: сертификата нет — «jsem připraven získat odbornou kvalifikaci dle zákona č. 250/2021 Sb.» / NV 194/2022 Sb.
- Каналы: только прямые работодатели (агентства закрыты картой); jobs.cz, prace.cz, Indeed. Отклик 1 из 10–15 при прямых рассылках на массовые позиции — норма рынка (проформа-объявления), не приговор.
- Почта: нейтральный адрес вместо protonmail-ника.

## Правка телефона в PDF (pymupdf, бесшовно)
Найти строку с номером (get_text('dict'), искать хвост номера), замерить фон ячейки пиксельным пробой (get_pixmap + мода светлых пикселей — фон часто СЕРЫЙ, не белый), redact-аннотация с fill=цвет фона, вставка insert_text с helv (расчёт ширины 0.556 em/цифра), проверка: пробы пикселей по строке + наличие текста в слое. Оригинал не перезаписывать — сохранять в новый файл.
