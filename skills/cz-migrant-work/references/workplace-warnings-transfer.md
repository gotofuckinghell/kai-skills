# Выговоры, перевод, позиции завода

## Выговоры (písemné upozornění) и §52f
- Несколько письменных выговоров за качество = стандартная дорожка к увольнению по §52f (неудовлетворительные результаты). Относиться серьёзно.
- Выговор обязан содержать конкретику (что не так) и давать разумный срок на исправление — без этого юридически слаб. Требовать цифры: «сколько банок, за какой период, какой процент от выработки, каков норматив».
- Испытательный срок: увольнение возможно без причины — если не уволили, работник нужен (дефицит рук = скрытая карта).

## Брак на линии
- Дефекты (нет краски, плохой лак, размазка) на декорёре часто процессные, не «ручные»: вязкость, клише, валики, скорость, приёмка после чужой настройки. Учёт вешают на смену, когда дефект обнаружили.
- Систему волнует только брак, дошедший до палеты. Прямой рычаг: самопроверка первой банки после остановок + выборочные проверки — месяц нуля на палете снимает почву с выговоров.
- Сменный журнал: состояние машины при приёмке, инциденты (время, дефект, действие). В момент дефекта звать мастера сразу, а не в конце смены.
- Если выговоры за аналогичный брак получает только он — избирательность: фиксировать, это материал для HR/inspektorátu.

## Запрос перевода (письмо)
- Перевод позиции — инструмент HR, не супервайзера. Письмо в HR, супервайзер в CC (не в обход, но и не похоронить). Электронное письмо для этого пользователя лучше разговора: силён в письме, боится конфронтации, письмо = запись.
- Формулировка: через качество («на позиции X в текущем режиме трудно удерживать качество стабильно; качество — приоритет; прошу позицию, где смогу работать надёжно») + вопрос про mzdu. НИКОГДА письменно «не вытягиваю / nezvládám».
- «Хочу попроще» → «позиция с меньшей ответственностью за финальный контроль».
- Разговор не может быть основанием увольнения; после испытательного — только процедура. Страх «уволят за письмо» — из старого опыта, не из чешского права.
- Медицинский резерв (последний, раскрывает здоровье): заключение závodního lékaře о противопоказании ночных смен обязывает работодателя перевести (§41 ZP).

## Позиции завода (производство банок), от простого к сложному по ответственности за качество
paletizér (палетизатор) → мойка (washer) → bodymaker → necker → внутреннее лакование → dekoratér (самая точная/стрессовая). Целиться в paletizér/мойку; некер и лак — та же история, что декорёр.

## Среда
- Исключение из рабочих WhatsApp-чатов + обсуждение за спиной: фиксировать инциденты с датами в лог; в письма жалобы без фактуры не включать. Просьба добавить в чат смены — нормальна; отказ с ухмылкой — факт в лог.
