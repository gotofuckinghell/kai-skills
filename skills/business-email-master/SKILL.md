## Единый порядок работы (комбинированный workflow)

### Шаг 0. Режим клиентского сервиса (ПРИОРИТЕТ)
Если пользователь отвечает клиенту, покупателю или заказчику (или пишет кому-либо письмо в контексте обслуживания) — использовать `references/customer-service-ru.md`: деловой тон с дружественным уклоном, максимальная вежливость, детализированность, структура «приветствие → благодарность → суть → доп. помощь → подпись». Принципы cold-email («короче = лучше», запрет вежливых формул) в этом режиме НЕ применять — они противоречат требованиям клиентского сервиса.

### Шаг 1. Определи тип и тон
- **Тип письма:** официальное / полуофициальное / дружеское / холодное продающее / двуязычное / рассылка
- **Тон:** formal (официальное), semi-formal (официально-дружеское), friendly (дружеское), urgent (срочное), minimal (минимализм)
- Несоответствие тона типу — главная ошибка (см. cultural calibration в benchmarks)

### Шаг 2. Собери контекст (не блокируйся на отсутствующих данных)
Для холодного письма: кому (роль, компания, почему именно он) → чего хочешь (встреча, ответ, демо) → ценность (конкретная проблема) → доказательство (кейс, цифра) → сигналы (funding, найм, LinkedIn).
Для обычного: цель → адресат → ключевые пункты → сроки → вложения.

### Шаг 3. Напиши по структуре
Универсальная структура (из email-writer-assistant):
```
To: / Cc:
Subject: (≤50 символов; [Urgent] / [Action Required] при необходимости)

Приветствие,
Абзац 1: цель письма
Абзац 2: основное содержание, одна идея на абзац
Абзац 3: ожидаемые действия и сроки
Подпись: Имя / Должность / Компания / Контакты
```
Для холодного письма — свой порядок: наблюдай → проблема → доказательство → один лёгкий CTA (см. cold-email-core).

### Шаг 4. Проверь качество (всегда)
- **Человечность:** прочитай вслух; звучит как маркетинг — перепиши. Без «I hope this email finds you well», «leverage», «synergy», «best-in-class»
- **Тема письма:** 2-4 слова lowercase для холодных; ≤50 символов для обычных
- **Один CTA.** Низкое трение: «Worth exploring?» / «Curious?» вместо 30-минутной встречи в первом касании
- **Факты:** проверить имена, даты, суммы, ссылки
- **Длина:** 25-75 слов оптимально для холодных (83% больше ответов под 75 слов)

### Шаг 5. Спам-аудит (если рассылка или сомнения)
Проверь на спам-триггеры: «free», «guarantee», «act now», CAPS, «!!!», числа и проценты в теме, эмодзи (см. subject-lines + email-review-compliance). Для рассылок — CAN-SPAM/GDPR/CASL: unsubscribe-ссылка, физический адрес, plain-text версия.

## Ключевые принципы (сводка по всем источникам)

1. **Короче = лучше.** Каждая фраза должна зарабатывать место. 25-75 слов для холодных писем.
2. **«Вы», а не «мы».** Читатель должен видеть свою ситуацию, а не твою компанию.
3. **Персонализация привязана к проблеме.** Если убрать персональный оупенер и письмо не сломается — персонализация не работает.
4. **Тема — как от коллеги, не от вендора.** «reply rates», «Q2 forecast», а не «Increase your ROI by 300%!»
5. **Follow-up обязателен.** 55% ответов приходят из follow-up, 48% продавцов не делают их вообще. 3-5 писем, растущие интервалы.
6. **Breakup-письмо — финал.** Отправил — больше не пиши.
7. **Один CTA, низкое трение.** Интерес-ориентированные CTA бьют запросы встреч.
8. **Культурная калибровка.** US — прямо и коротко; UK — вежливо и с инсайтами; DACH — данные и точность; Скандинавия — факты и равенство.
9. **Цифры не врут.** Средний reply rate 4-5.8%, excellent 10-15%. Проверяй ожидания по benchmarks.
10. **Спам-фильтры и комплаенс** — часть работы, не прихоть (Google порог: 0.1% жалоб).

## Что НЕ делать (сводный анти-чеклист)

- «I hope this email finds you well» / «My name is X and I work at Y» как открытие
- Jargon: synergy, leverage, circle back, best-in-class, leading provider
- Feature dumps — один proof point лучше десяти фич
- HTML, картинки, множественные ссылки в холодном письме
- Фейковые «Re:» / «Fwd:» темы
- Идентичные шаблоны с подменой {{FirstName}}
- 30-минутные встречи в первом касании
- «Just checking in» follow-up (минус 12% бронирований)
- Имя получателя в теме холодного письма (минус 12% ответов)
- Фейковая срочность, каунтдауны, «Act Now» (плюс 67% спам-флагов)
