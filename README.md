# Kai Skills

478 skills (SKILL.md format, agentskills.io standard) exported from Hermes.

## Install in Kai 9000 (Android)
1. Settings -> Linux Sandbox -> install sandbox
2. Settings -> Tools -> Skills -> Add Skill
3. Paste: `gotofuckinghell/kai-skills`
4. Pick skills from the list (each installs as `/skill-id` slash command)

## Structure
`skills/<skill-id>/SKILL.md` + bundled files.
